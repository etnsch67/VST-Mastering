# Monster Clone - installateurs automatiques

1. Creez un compte gratuit sur github.com et un nouveau depot (prive si vous voulez).
2. Envoyez-y tout le contenu de ce dossier (bouton "Add file" > "Upload files"), y compris le dossier .github.
3. Onglet "Actions" > "Build installers" > "Run workflow".
4. Attendez ~10 minutes, ouvrez l'execution terminee, telechargez en bas :
   - MonsterClone-Windows-Installer  -> MonsterClone-Windows-Setup.exe
   - MonsterClone-macOS-Installer    -> MonsterClone-macOS.pkg
5. Double-clic sur l'installateur : le plugin apparait dans votre DAW (rescan des plugins si besoin).
